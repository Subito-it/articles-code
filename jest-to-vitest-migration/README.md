# Jest → Vitest Migration Skill

A generalized [Claude Code](https://code.claude.com/) skill for migrating a frontend repository's test suite from Jest to Vitest.

## Using it

Install as a Claude Code plugin, or copy `commands/migrate-to-vitest.md` directly into your own project's `.claude/commands/` (or equivalent). Run it against a single file, a directory, or a whole repository — see the command's own `argument-hint`.
